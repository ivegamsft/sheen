# Sheen Onboard Skill

Agent-invocable companion to `docs/guides/consumer-lifecycle.md`. Executes the 5-phase onboarding lifecycle programmatically so a consumer repo can be fully integrated, inventoried, audited, and using sheen governance with a single skill invocation.

> **If you're seeing this skill for the first time after bootstrap:** that's
> correct — you're now past Phase 0. Continue with the prompts below to complete
> the onboarding lifecycle.

> **If you're trying to run `/sheen-onboard` but get a file-not-found error:**
> you haven't bootstrapped yet. Run the one-liner first:
> - Windows: `pwsh -c "iex (iwr https://raw.githubusercontent.com/ivegamsft/sheen/main/bootstrap.ps1).Content"`
> - macOS/Linux: `bash <(curl -fsSL https://raw.githubusercontent.com/ivegamsft/sheen/main/bootstrap.sh)`
> Then reset Copilot context (exit and re-enter CLI, or Reload Window in VS Code).

## Closes

GitHub issue #55 — `feat(docs): consumer lifecycle guide — agent-driven onboard skill (sheen-onboard)`

## Phases

| Phase | Action | Gate |
|---|---|---|
| 0 Bootstrap | Download sync scripts, create `.sheen.yml`, run initial sync | `sync.ps1` + `.sheen/manifest.json` present |
| 1 Integrate | Customise `.sheen.yml` allow-lists, re-run sync, reset context | `sheen-onboard` visible in `/` picker |
| 2 Onboard | Bootstrap token aliases, configure `materialize_tokens` | `dist/tokens/` builds without error |
| 3 Inventory | Run `sheen-metadata.json` scan on consumer assets | inventory report produced |
| 4 Audit | Run `checks.json` rules, `warn-rules.ps1`, `contrast-check.ps1` | zero CRITICAL fails |
| 5 Use | Wire agents, skills, instructions into consumer workflows | at least one agent invoked successfully |

## Sample Prompts

### Full lifecycle onboard

```
@sheen-onboard run the full onboarding lifecycle for this repo against
ivegamsft/sheen@main
```

**Agent flow:** `sheen-onboard` → `design-system-architect` (token inventory) → `accessibility-auditor` (contrast gate) → `design-reviewer` (first use)

**Output shape:**
```
## Sheen Onboarding Report
- Phase 0 Bootstrap:  ✅ sync.ps1 present, .sheen.yml created, initial sync complete
- Phase 1 Integrate:  ✅ .sheen/manifest.json synced (commit abc1234)
- Phase 2 Onboard:    ✅ dist/tokens/ built (80 tokens, 3 themes)
- Phase 3 Inventory:  ✅ 0 agents, 2 skills found in consumer repo
- Phase 4 Audit:      ⚠️  2 warn-level issues (W01 token-budget, W04 aria-keyboard)
- Phase 5 Use:        ✅ ux-designer agent successfully invoked

Gate: PASS (0 critical, 2 warnings logged as issues)
```

### Bootstrap only

```
@sheen-onboard bootstrap .sheen.yml and run sync for this repo
```

### Audit only

```
@sheen-onboard run Phase 4 audit against current .sheen/manifest.json
```

### Health check

```
@sheen-onboard generate an onboarding health report for this repo
```

## Config Bootstrap

When invoked, produces a `.sheen.yml` starter:

```yaml
# .sheen.yml — generated by sheen-onboard skill
source: https://github.com/ivegamsft/sheen.git
ref: main
materialize_tokens: true
```

## Output Schema

```yaml
discriminator: handoff-package
phases_completed: [0, 1, 2, 3, 4, 5]
gate: PASS | WARN | FAIL
critical_count: number
warn_count: number
tokens_built: number
themes: [light, dark, high-contrast]
issues_logged: [string]
```

## Agent Pairing

- Orchestrates: all 6 sheen agents (sequential lifecycle)
- Delegates to: `design-system-architect` (Phase 3), `accessibility-auditor` (Phase 4)
- Produces: onboarding health report, `.sheen.yml`, issue list for warnings
