# Design Bootstrap

Start a new design system from zero and deliver a coherent starter foundation.

## Workflow
1. Read/apply the [discovery intake](references/discovery-intake.md); capture product intent, brand constraints, and platform requirements.
2. Seed core + semantic token primitives and initial light/dark/high-contrast themes.
3. Define baseline component/spec conventions and IA/navigation starter structure.
4. Establish accessibility, usability, and content guardrails for subsequent waves.
5. Output a staged rollout plan for follow-on skill execution.

## Guardrails
- Do not overfit the initial system to a single page mock.
- Do not skip accessibility and theme-completeness constraints.
- Do not introduce unstable naming that breaks future versioning.
- Do not treat client assertions or assumptions as validated user evidence; route discovery preparation/synthesis to `user-research`.

## Output
- Initial token foundation and theme strategy.
- Bootstrap plan for components, IA, and governance follow-up tasks.
- Discovery-linked scope, assumptions, unknowns, restrictions and validation owners.
