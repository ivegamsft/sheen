# Style Guide Template

> Use this template as a starting point when running the `style-guide-authoring`
> skill. Copy this directory into the consumer repository and fill in each section.
> Delete sections that do not apply; do not leave placeholder text in a published
> guide.

## How to use this template

1. Copy `templates/style-guide/` into your consumer repo (e.g. `docs/style-guide/`).
2. Run the `style-guide-authoring` skill to populate each section.
3. Publish via mkdocs or your docs platform of choice.
4. Register the published URL in your `.sheen.yml` under `metadata.style_guide_url`.
