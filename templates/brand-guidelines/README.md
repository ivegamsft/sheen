# Brand Guidelines Template

> Use this template when running the `brand-identity` skill or authoring a brand
> guide for a consumer product. Copy `brand-guidelines.md` into your consumer repo
> (e.g. `docs/brand/guidelines.md`) and populate each section.

## How to use this template

1. Run the `brand-identity` skill to generate a draft.
2. Review with the brand owner to confirm voice, color, and logo rules.
3. Validate token alignment with `color-system` and `typography` skills.
4. Publish and link from the consumer `.sheen.yml` under `metadata.brand_guide_url`.
