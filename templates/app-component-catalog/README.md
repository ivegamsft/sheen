# App Component Catalog Template

> Use this template when running the `app-component-catalog` skill in audit
> or generate mode. Copy `component-entry.md` once per accepted logical
> component into the consumer repository's chosen gallery representation
> (a docs site, a design tool, or any other format the downstream owns).
> Delete bracketed placeholder text before publishing an entry.

## How to use this template

1. Copy `templates/app-component-catalog/component-entry.md` into your
   consumer repo's app-specific component gallery (any location/format you
   own — Sheen does not prescribe one).
2. Run the `app-component-catalog` skill in audit mode to populate entries
   from evidence, or in generate mode to add one new/updated entry.
3. Complete every section — identity, usage, placement, composition, styling
   abstractions, data/content, behavior/states, responsive behavior, and
   selection metadata.
4. Link the entry to your Experience Blueprint pages/flows and App Layout
   Catalog regions once those catalogs exist for your application.
5. Publish the gallery in your chosen representation; a visual preview is
   optional and never replaces the logical specification.
