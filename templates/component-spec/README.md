# Component Spec Template

> Use this template when running the `component-spec` skill. One file per component.
> Copy `component-spec.md` into the appropriate location in your consumer repo
> (e.g. `docs/components/<name>.md`) and populate each section.

## How to use this template

1. Run the `component-spec` skill to generate a draft for your component.
2. Review and complete each section using the sheen component contract
   (`sheen-30-components-states` instruction).
3. Validate ARIA completeness with `accessibility-audit`.
4. Register the component in your style guide component index.
