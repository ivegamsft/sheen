# Design Review Template

> Use this template when running the `design-review` skill. One file per review
> session. Copy `design-review.md`, populate the metadata and findings, and
> attach to the PR or design file being reviewed.

## How to use this template

1. Run the `design-review` skill against the artifact under review.
2. Complete each section of `design-review.md`.
3. Attach the completed review to the PR, Figma file comment, or design ticket.
4. Route critical and major findings to the design owner for resolution before
   sign-off.
