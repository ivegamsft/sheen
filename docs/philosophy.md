# Philosophy

basecoat-sheen exists to make product quality feel intentional, predictable, and
governed rather than subjective.

## Core values

- **Effortless** — reduce friction and decision load
- **Calm** — avoid noisy, distracting interfaces
- **Personal** — respect accessibility and context
- **Familiar** — align to known patterns
- **Complete + Coherent** — consistent behavior across states and flows

## How sheen works

1. Tokens define visual truth.
2. Skills define repeatable authoring/audit workflows.
3. Agents orchestrate skills by mandate.
4. Instructions provide ambient guardrails.
5. Validation enforces non-negotiable quality thresholds.
