# basecoat-sheen docs

basecoat-sheen is the design governance finish coat for basecoat. It packages
design skills, agents, instruction layers, and DTCG tokens so teams can apply a
consistent craft bar across UX, accessibility, brand, and handoff.

## What ships here

- `skills/` — invokable design workflows with routing evals
- `agents/` — composed design-role orchestrators
- `tokens/` — core, semantic, and themed DTCG token tiers
- `instructions/` — always-on guidance layers
- `checks.json` — governance checks and validation expectations
