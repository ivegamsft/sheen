# Foundations

Foundations define the reusable primitives that all components and patterns rely
on: color, type, spacing, shape, elevation, materials, and motion.

Primary assets:

- Skills: `design-tokens`, `color-system`, `typography`, `layout-grid-spacing`,
  `iconography`, `motion-elevation`, `theming`
- Tokens: `tokens/core/*`, `tokens/semantic/*`, `tokens/themes/*`
