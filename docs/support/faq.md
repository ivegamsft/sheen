# FAQ

## 1. Where do I start?

Use the [10-minute quick-start](../getting-started/quick-start.md), then pick an
[adoption mode](../getting-started/adoption-modes.md).

## 2. Why is a synced asset missing?

Your allow-list is probably too narrow. Check `.sheen.yml`, then re-sync.

## 3. Can I keep basecoat and sheen together?

Yes. The namespaces are separate, so `.basecoat.yml` and `.sheen.yml` can live
side by side.

## 4. Should I pin `main` or a release tag?

Pin a release tag when you need stable consumer behavior. Use `main` only for
active evaluation.

## 5. What should I read for exact behavior?

Start with the [full specification](../reference/full-specification.md) and the
[validation checks](../reference/validation-checks.md).
